# Notes for app review

Agentdeck controls coding agents on the user's own computers, so the app is empty until a
computer is linked. For review:

1. Keep a computer online with `agentdeck` installed, signed in as the review account
   (`agentdeck login --email review@…`), with one repo added and one profile logged in.
2. Give the reviewers that email; they sign in with the emailed link (or provide a demo
   password account if the console requires one, then remove it after review).
3. Suggested path: Work → the repo → New task → watch the agent → approve its permission →
   Changes → Ship.

The app has no in-app purchases, ads or tracking.
