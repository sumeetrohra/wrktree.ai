Your coding agents, in your pocket.

Drive Claude Code, Codex and Gemini CLI running on your own computers from your phone. Watch them work, approve what they do, review the code and ship it, from anywhere.

Install Source on GitHub 

npm install -g agentdeck

1. Install on your computer

The free CLI runs a small daemon next to your agents. They keep using your own logins.

2. Sign in on your phone

Same email on the app and on each computer. Your computers show up by themselves.

3. Start a task

Pick a repo, describe the work. The agent gets its own branch and gets going.

Watch it work

Replies stream in as the agent writes them, with its plan, the files it reads and the commands it runs.

Approve from a notification

When the agent wants to edit a file or run a command, you decide, wherever you are.

Review and ship

Read the changes with syntax highlighting, ask about a line, commit, push, and merge a pull request the agent drafted.

Preview the app

Open the app the agent is building on your phone, hot reload included, without exposing a port.

Many accounts, no dead ends

See each account's usage. When one hits its limit, hand the chat to another and keep going in the same branch.

One setup for every agent

Share instructions, MCP servers and skills across Claude Code, Codex and Gemini profiles.

Your code stays on your computers

Agents run on your machines with your credentials. The phone talks to them end to end encrypted through a relay that only ever sees ciphertext, so not even the relay operator can read your chats. It's open source under MIT, and you can run your own relay. How it's secured · Self-host the relay
