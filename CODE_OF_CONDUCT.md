# Code of conduct

Everyone is welcome here. Be kind, assume good faith, and keep discussions about the work.

Not acceptable: harassment, personal attacks, discriminatory language or imagery, publishing
others' private information, and sustained disruption.

Maintainers may edit or remove comments, commits and issues that break this code, and may ban
contributors who do so repeatedly. Report problems to **conduct@agentdeck.dev**; reports are kept
confidential.

This code is adapted from the [Contributor Covenant](https://www.contributor-covenant.org/),
version 2.1.
